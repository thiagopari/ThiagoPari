My part: the Bayesian gate, the arm64 GR00T + LIBERO cell service the supervisor agent calls, and the Learner's Permit control plane. Teammates built the fleet simulation and Isaac Sim warehouse, the integration and Docker stack, the supervisor LLM setup, the Discord bot and the dashboard.

Problem

An AI agent that can trigger robot skills needs a rule for when a skill can be trusted. Vision-language-action (VLA) policies vary widely from task to task, so that rule should come from measured trials of each skill, not from a prompt.

The Gate

  • Each trial succeeds or fails. With a uniform prior, a policy's success rate has a Beta(1 + s, 1 + f) posterior.
  • The gate opens only when the best candidate has P(rate ≥ 0.8) ≥ 0.95. 13 straight successes (0.956) are the shortest run that opens it; 12 give 0.945. In C-3 the candidate opened it at 15/15 (0.972).
  • Thompson sampling chooses which candidate checkpoint gets the next batch of trials, so trials flow to the policy most likely to be best.
  • An "unattended" tier asks for P(rate ≥ 0.99) ≥ 0.95, which takes 298 straight successes: high reliability has to be paid for in trials.

The trial cap matters as much as the threshold. Exact probabilities for the single-policy case, batches of 4:

Result on the GB10 (Oct 3)

The models and simulators ran locally on one Dell Pro Max GB10: a Qwen3.6 supervisor model on vLLM, an agent sandbox, and two GR00T N1.7 policy servers on NVIDIA's LIBERO checkpoints, in containers built for arm64 and staged offline before the event. What the Hackathon Exposed, and the Fix

At the GB10 event only the agent's prompt respected the gate; no code checked it. Learner's Permit, the continuation, puts the gate in code: a planner (Nemotron) can reach a GR00T skill only through one endpoint, POST /run.

  • A Cedar policy (an authorization-policy language) checks the role from the session, never from the LLM; anything else the planner emits is dropped.
  • The skill must hold a license earned in trials, scoped to the conditions that were tested and revoked when live results slip.
  • A web datasheet check can block a pick but never allow one. Missing context means deny.

Status (Oct 5): control plane, console and a refuse → earn → block → revoke demo, with 64 passing tests and CI, all on a mock runner with offline stand-ins for Nemotron and the datasheet check. GR00T trials in Isaac Sim come next; no Isaac Sim numbers yet.
