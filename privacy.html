Agent-Town Privacy Policy

Last updated: October 23, 2026

Agent-Town is a personal tool built and used only by Thiago Pari. It is not offered to the public.

What it accesses

With the owner's consent, it reads and edits the owner's own Google Calendar so that a personal assistant can plan the owner's day.

What it does with that data

Calendar data stays on the owner's own computer. It is not sold, shared with third parties, or used for advertising. Google user data is used only to provide this calendar feature.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
