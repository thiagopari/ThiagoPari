Learner’s Permit: Licences for Robot Skills

Real vs. simulated: Every robot run is in simulation (Isaac Sim via RoboLab); there is no physical robot. The episodes, licences and revocations shown are real runs.

The Idea

An AI may command a robot skill only after trials prove it, only where it was tested, and only until the evidence changes.

How a Request Gets Through

  1. Plan: A Nemotron planner sees only the skill catalogue.
  2. Gate: The only path to the robot is POST /run, where a Cedar policy checks the licence and its scope, and live web checks (Tavily) look up datasheets and recall notices. A drill-driver kit whose spec sheet says 1.724 kg is refused under a 1.0 kg licence.
  3. Act: GR00T N1.7-DROID runs the skill in Isaac Sim on Nebius AI Cloud (RTX PRO 6000).
  4. Watch: After every run, Nemotron-3.5-Super-VL compares the camera frame with the one the licence was earned on. When the floor changed from tile to wood, the licence was revoked even though the run succeeded.
