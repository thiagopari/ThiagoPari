The Idea

An AI agent that scopes an underwater ROV inspection, prices it from a fixed rate card, takes a 30% deposit through PayPal, and books the dive slot. All in one conversation.

How a Booking Works

  1. The customer describes the job: dock, pilings, seawall or hull. Claude asks only the questions that change the price.
  2. A fixed rate card on the server prices it, so the agent can’t be talked down; similar past jobs (demo data in Elasticsearch) give context for the estimate.
  3. PayPal takes a 30% deposit, and the slot is booked only after the server verifies the payment.
  4. The booking produces a pre-dive plan and an invoice draft, and shows up in the contractor’s operations view.
